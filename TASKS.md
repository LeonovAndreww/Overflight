# TASKS — бэклог Overflight

Задачи расставлены по приоритету: сверху важнее. Каждую можно взять без переписки с
автором. Контекст — в [HANDOFF.md](HANDOFF.md), особенно раздел 6 «Требования
пользователя». Перед любой визуальной правкой сверяйся с фото в `external/photos/` и
смотри результат сам на скриншотах. Автору скриншоты не отправлять.

Общие правила:
- коммиты короткие conventional (`feat/fix/build/refactor/docs`), без «книг»;
- одна задача — один или несколько небольших коммитов;
- не пушить, не тегать, не публиковать без слова автора;
- версия остаётся 0.2.0.

## P0 — окружение

### T0.1 Поднять сборку на сервере — ГОТОВО 21.11.2026 (тесты ядра и все четыре jar собраны)
- Поставить Temurin JDK 21 и 25 (adoptium apt или sdkman).
- В `~/.gradle/gradle.properties` прописать `org.gradle.jvmargs=-Xmx2g`,
  `org.gradle.workers.max=2` и `org.gradle.java.installations.paths=<jdk21>,<jdk25>`.
- `./gradlew build --no-daemon` должен собрать четыре jar в `backends/*/build/libs/` и
  пройти тесты `overflight-core`.

**Готово, когда** сборка и тесты зелёные. Рецепт записать в HANDOFF.md §4, если он
отличается.

### T0.2 Запуск клиента под Xvfb с программным рендером — ГОТОВО 21.11.2026 (llvmpipe GL 4.5, 3 скриншота из 26.2, 50 мин при нагрузке ~14)
- Поставить `mesa-utils libgl1-mesa-dri` и проверить
  `xvfb-run -a glxinfo | grep "OpenGL core profile version"` (нужно ≥ 3.3).
- Запустить
  `LIBGL_ALWAYS_SOFTWARE=1 xvfb-run -a -s "-screen 0 1920x1080x24" ./gradlew :backends:fabric-26.2:runClient --args='--quickPlaySingleplayer "New World"'`.
- Флаг `backends/fabric-26.2/run/overflight-autoshot` уже лежит. Клиент должен сам войти,
  сделать три скриншота в `run/screenshots/` и выйти.
- Если llvmpipe не тянет 26.x (Vulkan/GL-требования), записать, что именно падает, и
  найти обходной путь: zink, другая версия Mesa, Docker-образ с Mesa.

**Готово, когда** агент получает скриншоты неба из настоящей игры без человека.

## P3 — порты на другие версии и загрузчики

Цель автора — как можно больше версий, включая старые популярные **1.5.2, 1.6.3, 1.7.5,
1.7.10** (1.7.10 — его личная цель) и **3–4+ загрузчика**.

Общий подход:
- ядро `overflight-core` без Minecraft уже есть;
- для старых версий нужна Java 8, значит ядро должно собираться с `--release 8` (проверить
  синтаксис: var, records, switch-выражения и т. п.) или иметь отдельную сборку;
- рендер на старых версиях — фиксированный конвейер GL11 (Tessellator), миксины через
